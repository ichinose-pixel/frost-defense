# v13: 建築の選択・地面UI・序盤調整

v12の実機フィードバック: HUD・水色表示・建築時の押し出しは問題なしとの報告。今回も透明DOMを増やさず、その構成を維持。

## 変更

- 設備の地面表示は設備と同じX/Z座標へ。画面座標の下方向オフセットも撤去。
- 素材・Lvの詳細は近くの1設備に限定。遠い設備や完成済み設備の輪を常時強調しない。
- 未建築の設備は実際の占有サイズの四角い輪郭で表示。重複する円盤・リングを廃止。
- 木柵は1×4マス。発射台（見張り台）は2×2マス。炎塔・倉庫も2×2の当たり判定に統一。
- 見た目、建築中の土台、地面輪郭、プレイヤー衝突、敵衝突は共通の占有領域を使用。
- 建築は外周から0.7マス以内で約0.8秒停止すると着工。移動中は着工しない。離れる・移動入力することで途中の待ち時間をリセット。
- 1回の停止で実行する建築/強化は1件。完成直後の連続強化による意図しない消費を防ぐ。次の建築/強化は一度移動して再び停止。
- 建築費を引くのは着工時のみ。完成予定地と重なる場合は完成を待ち、プレイヤーを押し出さない。
- 木柵の配置を間引き、拡大した壁が重ならず、全設備完成後も通れる隙間を確保。18建築地点（木柵10・見張り台4・火炎塔2・倉庫2）。
- 地形生成/資源再生は建築地点を避ける。既存の自由移動と自動採集を維持。
