# v16 — 霜翼竜

課題: ボスの位置・出現・撃破が分からず、気づかないうちにクリアしてしまう。

- 通常兵の拡大型を廃止。濃紺の胴体、水色の翼膜、氷の角、尾を持つ独自ボクセルドラゴン。翼幅は約7.5マス。既存作品のモデル・画像・音声は使用しない。
- Day7で実際に出現した瞬間に専用バナーとSE。最初の2.2秒は飛来中で攻撃対象外。その後は従来と同じ865HP。ほかの敵は通常どおり戦う。
- 壁を飛び越えて中央へ接近し、半径6マス付近を旋回。翼が羽ばたき、予兆中は高度を下げて中央へ顔を向ける。
- 拠点へのブレスは旋回中4.5秒周期。直前1.25秒に足元リングと専用HUDで予告。命中時38ダメージ、燃料11.4減少。旧地上ボスの壁/拠点近接攻撃から変更しているため、難易度は実機で要調整。
- 照準・矢の追尾・命中判定は空中の胴体に統一。射程は従来の地上位置基準を維持。見張り台・住民・プレイヤーの自動射撃、火炎塔が引き続き有効。
- 画面上部に霜翼竜のHPと行動状態を常時表示。画面外の場合は表示枠の端にBOSS方向マーカー。プレイヤー移動・カメラの強制移動は追加しない。
- 撃破時は通常敵の0.42秒より長い1.4秒で崩れ、そのままv15のステージクリア演出へ接続。残敵撤退に重複報酬は付けない。
- 巨大な透明DOM/CanvasTextureは追加しない。地面予兆は不透明リング、ブレスは短時間表示する1メッシュ。羽・地面マーカー・ブレスは敵モデル配下で一緒に破棄する。

`src/dragon.js` に形状、飛行、予兆、照準ヘルパー、専用HUDを分離。20ファイルをビルドで結合。

検証: 33件の回帰テスト。空中命中、登場中の攻撃抑制、壁越え、予告後のブレス1発、UI/モデルのリトライ清掃、画面外マーカー、撃破からステージクリアを確認。
実際のモデル頂点を使った簡易ソフトウェア描画でシルエットも確認。確認環境はWebGL非対応のため、実機の夜景・羽ばたき・SE・難易度・性能は未確認。

実機確認: v16のDay7で出現バナー→専用HP→大きな翼またはBOSS方向表示→氷息予兆→撃破を追えること。射程内で自動迎撃でき、低空時にもキャラが勝手に動かないこと。強い設備で素早く倒せる場合も、出現と撃破が分かること。
