# v14 iPhone Safari実機確認

最初の確認は5〜10分。開始画面が **v14** になっていることを確認してください。古い場合はページを再読み込みします。URLは変更しません。

1. 縦向きで開始。木材・石炭・鉄・Day・気温・燃料・拠点HPが表示され、ノッチに重ならないこと。
2. 下半分からドラッグして移動。指を離すと停止。画面上寄りからも移動可能。2本目の指で方向が飛ばないこと。
3. 木/石炭に近づく。資源表示が増え、道具の振り・立体破片・吸引・回収SEが出ること。木の幹・雪冠・鉱石の細部が採集後に残らないこと。移動しながらでも資源が現在のキャラ位置へ吸い込まれること。
4. 木柵の中心または端で0.8秒立ち止まり、足元ゲージが満ちると建築開始。移動中に通過するだけでは建たない。約0.78秒で組み上がり、重なっている間は完成を待つ。キャラが勝手に移動しない。離れると完成すること。
5. 夜の撃破で軽い吹き飛び・破片・COMBO音。強い画面揺れや一瞬の停止が増えていないこと。
6. 壊された木柵/塔に同じ場所のリングと「再建」が戻る。素材不足分だけ赤くなり、足りれば近づいて再建できること。
7. 建築中にゲームオーバー→リトライ。旧建築や強化済み拠点の残骸が出ず、HUDが残ること。
8. Safariをバックグラウンドへ→復帰。勝手に歩き続けないこと。縦横回転・アドレスバー伸縮後に画面がずれないこと。
9. PCブラウザでも起動し、WASD/矢印で移動、HUDが上部に見えること。
10. 資材を使うと資源別の小片が建築先へ飛ぶ。移動しても飛び先は変わらない。背中の資源は概量、HUDは正確な在庫で、演出終了時に二重消費されないこと。
11. 拠点Lv2〜4で道具の外見が変わること。昼は夜までの秒数、夜は残敵数を表示し、燃料/HP低下時の色が見分けられること。

## 水色表示が再発した場合

以下を一緒に記録してください。スクリーンショットまたは10秒程度の画面録画が有用です。

- iPhone機種、iOSバージョン、Safari本体かアプリ内ブラウザか。
- v14表示を確認したか。
- 開始直後/指を置いた時/採集時/建築時/夜/縦横回転/復帰直後のどこで発生したか。
- 指を離すと消えるか。端末回転・再読み込みで変わるか。
- 水色部分がHUDの前にも出るか、3D画面だけを覆うか。

HUDまで覆うならDOMレイヤー/合成、3D画面だけならWebGL側を優先して切り分けます。これは仮説であり、スクリーンショットだけで原因確定とはしません。SafariのWebインスペクタが使用可能ならConsoleのエラーとWebGL context lossの有無も記録します。
