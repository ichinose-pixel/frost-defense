## 実装

- HUD: 資源3種類を上段、日数・気温・燃料・拠点HPを下段に固定。資源名、燃料/HPゲージ、低残量色、資材変動色を追加。昼は夜までの秒数、夜は未出現を含む残敵数を表示。
- 地面UI: 近接対象1件・建物中心へのラベル表示を維持。文字の建築%表示を足元の不透明な細いゲージへ変更。停止待ち、組立、重なり待ちを確認可能。
- プレイヤー: 背中に木・石炭・鉄を最大各4個表示。1個は在庫25単位の帯域を表す概量で、正確な数量はHUD。容量制限や資源の所有先変更はない。採集時の道具振り、拠点Lvに応じた道具外見を追加。
- 採集: 元の論理ブロックを一括除去して報酬を加算する処理は維持。破片を最大96個のInstancedMeshに集約。回収粒子は散開後に移動中のキャラクターへ追従。
- 納品: 建築・設備強化・拠点LvUP・補給の支払い成功後に弧を描く資源演出を開始。資源量の書き換えを演出側に置かない。建築前の無料納品に見える旧粒子を除去。
- 木・鉱石: 論理ブロックを増やさず、描画時に幹の細部・葉の濃淡・雪冠・鉱石の稜線へ分割。既存の地形InstancedMeshの1描画にまとめる。描画枠が不足する場合は詳細度を落とし、論理セル用枠を優先。
- 通知: 採集ごとの重複トースト、設備強化ごとの大きな画面中央バナーを削減。現場のポップとHUDで伝え、拠点LvUPと昼夜切替は中央バナーを維持。

## コードと負荷予算

`src/feedback.js`: プレイヤー装備・ストック表示、立体破片、納品、行動ゲージ。資源・HP・移動座標を書き換えない。
`src/voxel-style.js`: 論理ブロックから描画専用の小ボクセル形状を生成。
18ファイルをビルドで結合。実行時パッチ・重複関数上書きは追加しない。

- 回収＋納品: 合計128メッシュ以内、既存プールを再使用。納品は1回あたり最大12個。
- 立体破片: 最大96インスタンス、追加の描画1回。終了後は件数0。
- 背中の資源: 固定12メッシュ。毎フレーム作り直さない。
- 足元ゲージ: 全地点で共有する1メッシュ。
- 地形描画容量: 8,000→12,000。実際の件数のみ描画。スマホでの実測FPSは未確認。
