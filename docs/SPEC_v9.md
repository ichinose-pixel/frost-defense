# Frost Defense v9 仕様書

## コア方針

- 操作は移動のみ。採集・建築・進化・戦闘・拠点確保は接近による自動処理。
- 空中UIを減らし、Lv・建築/進化コスト・外部拠点情報は地面デカールで表示する。
- 序盤は中央拠点づくり、中盤は領土拡張、終盤は複数拠点防衛とDay7ボス戦へ移行する。

## 進行

### Day1-2: 中央拠点

- 木材/石炭採集
- 木柵・見張り台建築
- 拠点Lv2で外部拠点確保を解禁

### Day2-4: 領土拡張

- 製材所: 木材自動生産
- 炭鉱: 石炭自動生産
- 生存者キャンプ: 住民追加
- 拠点Lv3で鉄鉱山解禁
- 鉄は上位拠点進化に必要

### Day4-6: 複数拠点防衛

- 鉄鉱山・研究所跡地を確保
- 外部拠点も夜襲対象になる
- Night Modifierに応じて防衛方針を変更

### Day7: Final Night

- 巨大ボスを含む最終襲撃
- 撃破でSTAGE CLEAR

## 外部拠点

| 拠点           |     解放 | 効果                   |
| -------------- | -------: | ---------------------- |
| 製材所         | Base Lv2 | 木材 +6 / 約4秒        |
| 炭鉱           | Base Lv2 | 石炭 +4 / 約4秒        |
| 生存者キャンプ | Base Lv2 | 住民 +1                |
| 鉄鉱山         | Base Lv3 | 鉄 +2 / 約4秒          |
| 研究所跡地     | Base Lv4 | 塔・プレイヤー火力強化 |

## 敵タイプ

- 狼: 高速・低HP
- 盗賊: 標準型
- 重装兵: 低速・高HP
- 破城兵: 壁を優先して破壊
- 投射兵: 中盤以降に混入する特殊兵
- 巨大ボス: Day7最終敵

## Night Modifier

- 静かな夜: 通常襲撃
- 猛吹雪: 見張り台射程低下
- 狼の夜: 狼比率増加
- 燃料危機: 燃料消費増加
- 重装襲来: 重装兵比率増加
- 破城の夜: 破城兵比率増加
- 巨大な足跡: 次のボス戦予告

## UI

- 建築地点: 地面に設備名 + 必要資源
- 完成設備: 地面にLv + 次Lv必要資源
- 中央拠点: 地面にBase Lv + 次Lv必要資源
- 外部拠点: 地面にロック条件/確保状態/生産効果
- 上部HUDは資源・Day・温度・燃料・拠点HPのみに限定

## サウンド

Web Audio APIによる軽量SE。

- 木材/石炭/鉄採集
- 建築完了
- 設備進化
- 射撃/火炎塔
- 撃破/コンボ
- 夜襲開始
- 拠点LvUP
- 外部拠点確保/生存者救助
- Day7ボス警告

## デザイン

- 当たり判定の粗さは維持し、見た目のみ細密ボクセル化。
- プレイヤーの服飾ディテールを追加。
- 外部拠点を設備ごとに異なるシルエットで制作。
- 地面UIによりプレイ領域を遮らない情報設計を採用。
