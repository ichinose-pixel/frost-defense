# v17 — 画面ずれ・水色表示の切り分け

報告端末での直接再現は未確認。v14.1の位置補正後にも再発したため、位置補正を廃止し、天候描画も除去する。

- 表示枠はCSSの固定原点・100dvh（非対応時100%）で配置。VisualViewportのoffsetTop/Leftを加算しない。
- Canvasとカメラの比率は枠のgetBoundingClientRectの実寸を使用。リサイズ・復帰・ResizeObserverで再確認。寸法が同じ場合はCanvasを再設定せず、操作もリセットしない。
- 雪の720粒子と霧を削除。猛吹雪イベントと射程低下を停止。昼夜進行・燃料・敵編成イベントは維持。
- 炎と破片のPointsは遠近によるサイズ拡大を停止し、画面上の小さいサイズに固定。雪粒子がカメラ付近で拡大する可能性を原因候補として除去したもので、原因確定ではない。
- WebGL背景を暗色に固定。クリア時も背景の水色への変化を止める。地面の雪・氷の不透明ボクセルと昼夜の照明変化は維持。
- ジョイスティックの白い半透明塗りを除去。土台は枠線、ノブは不透明。

34件のテスト合格。枠とVisualViewportが異なる場合の寸法、同サイズでの再設定抑制、天候除去、近接時に拡大しない粒子、ステージ・ドラゴンの既存テストを確認。
実機でChromeの上下ずれ、水色表示の非再発、縦横回転、ブラウザバーの開閉・復帰を確認する。再発時は画面録画と機種/ブラウザを記録する。
