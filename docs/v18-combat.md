# v18 選択防止と戦闘の視認性

## 水色表示

ユーザーの実機確認で、テキスト／領域選択が水色表示の原因と判明。
ゲーム画面全体と子要素へ-webkit-user-select:none、user-select:none、
-webkit-touch-callout:none、-webkit-user-drag:noneを指定。
selectstart／dragstart／contextmenuをゲーム枠内で抑止し、Canvas操作開始時に既存選択を解除。
ボタンのpointerdown／clickは枠全体では止めない。v17の雪・霧停止と表示枠処理を維持。

## 攻撃の見やすさ

自キャラは見た目を18%、通常敵は15%拡大。移動速度、当たり判定、採集／攻撃範囲は従来通り。
自キャラに銃を追加し、0.2秒の射撃姿勢と反動、約0.09秒の不透明な発射光を表示。
従来は射撃姿勢が次フレームで戻っていた。弾は太さ0.07→0.14、長さ0.55→0.95、
夜の照明に埋もれないMeshBasicMaterialに変更。弾速・射撃間隔・通常敵への威力は維持。
追加の画面シェイク、操作ボタン、巨大な透明描画はない。

## ボス

Day7 HP：865→ステージ1=1400、2=1600、3=1800。
飛行装甲中は被ダメージ60%、氷息の予兆／発射中は125%。全味方のdamageEnemy経由で適用。
HP半分以下では氷息周期4.5→3.6秒。予兆は周期末尾1.25秒、1回の威力38は維持。
ボスHUDに装甲・弱点露出・怒りを表示する。
通常敵の数・HP・序盤難易度は維持。実機の撃破時間・拠点残HPを見て次回調整する。

## 検証

ゲーム回帰テスト、装甲／弱点／怒り、発射演出の保持と再挑戦リセット、選択イベント抑止を検証。
同じ資産をiOS／Androidへsyncし、Android APKはCIで再ビルド。
実機の長押し／ドラッグで選択が出ないか、銃撃の見やすさ、ボスの難度はユーザーテストが必要。
