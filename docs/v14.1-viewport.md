# v14.1 — Chromeの画面ずれ対策

報告: 上側約20%が見えず、下側も欄外にはみ出す。

確認した構造上の問題: v14はCanvas高さだけVisualViewportを参照し、幅・HUD・モーダルはレイアウトビューポート基準だった。VisualViewportの位置変更も監視していなかった。報告端末での直接再現は未確認のため、原因確定とはしない。

対策:

- Canvas・HUD・ダイアログ・地面ラベル・ジョイスティックを同じgameViewport内へ収容。
- 実際の表示幅・高さ・上下左右オフセットを同時適用。子要素はその枠内の座標で配置。
- ブラウザのリサイズ、VisualViewportのリサイズと位置移動、ページ復帰で再同期。
- ポインターと3Dラベルを枠内座標へ変換。枠だけ移動して操作がずれる状態を防ぐ。
- bodyのスクロールを固定。開始・リトライ画面は枠内でスクロール可能。
- WebGL起動前から枠を適用し、起動失敗表示も表示範囲内に置く。

検証: 25件の回帰テスト。追加テストは140pxの上オフセット、横オフセット、縦横回転、VisualViewport非対応時の代替サイズ、ジョイスティック位置を確認する。実際の端末での解消確認はユーザー確認待ち。

実機: 開始画面のv14.1表示を確認。画面上下、Chromeアドレスバー開閉、縦横回転、アプリ復帰、指の位置とジョイスティックの一致を確認する。
